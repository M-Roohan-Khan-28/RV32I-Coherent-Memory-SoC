## New bounded subsystem

Required command: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/run_coherent.ps1 -OutputDir <fresh-directory>` with `MODELSIM_BIN` pointing to ModelSim Intel FPGA Starter Edition 2020.1. The wrapper requires actual pass markers and zero simulator errors from **both** the subsystem bench and two-core program bench. The current runner requires at least 71 subsystem scenarios, 1,400 subsystem checks, 128 program checks, an observed contention stall, and the expected reset-aborted transaction. It checks process exit codes and times out each tool after 120 seconds. The benches have cycle and per-transaction bounds. ModelSim itself can return process exit 0 after `$fatal`, so transcript errors and markers are required too.

The independent oracle is a byte-addressable word array plus a doorbell value. It takes requests at acceptance and applies writes only at successful response. It does not use the DUT's RAM, cache data, FSM or pending registers to form expected data. After every directed or seeded operation it additionally checks each cache line against the oracle and checks that two caches never both own the same address exclusively.

Directed scenarios cover cross-core visibility, shared reads, ownership transfer, held invalidation, alternating and simultaneous same-address writes, independent addresses, conflicting tags and clean eviction, byte strobes, MMIO bypass, address errors, stalled memory and response, and reset cancellation. Forty deterministic operations and eight additional simultaneous pairs use seed `0x28A6BEEF`. The pairs hold memory-ready low for a seeded duration, leaving one requester queued while the first operation waits. The scoreboard checks observed acceptance order and an independent round-robin rule. This is scenario/check-count evidence, not measured functional or code coverage.
